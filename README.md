# Download anime videos — сайт проекта

Статичная версия промо-страницы расширения **Download anime videos** (скачивание сезонов аниме с yummyanime.tv).
Собрана из исходников perchance-генератора: шаблонные вставки подставлены, живое демо работает через публичные CORS-прокси.

## Что внутри

| Путь | Что это |
| --- | --- |
| `index.html` | Вся страница: один файл, весь CSS внутри. Внешних CDN нет. |
| `lib/` | Модули `yani.js`, `kodik.js`, `util.js` — их использует живое демо на странице. |
| `assets/icons/` | Иконки расширения (16/32/48/128) — иконка сайта. |
| `assets/banner.png` | Баннер проекта (1200x630), он же картинка для соцсетей. |
| `Download-anime-videos-v1.0.0.zip` | Готовый архив расширения — на него ведёт кнопка «Скачать .zip». |
| `extension/` | То же самое, но уже распакованное: сразу грузится через «Загрузить распакованное расширение». |

## Как запустить

Просто открыть `index.html` двойным кликом **недостаточно**: браузер блокирует ES-модули по `file://`,
поэтому демо не загрузится (остальная страница при этом отобразится нормально).

Варианты:

```bash
# локально
python3 -m http.server 8080
# затем http://localhost:8080
```

Либо загрузить папку на любой статичный хостинг: GitHub Pages, Netlify, Cloudflare Pages, Vercel —
никакой сборки не нужно, это чистый HTML/CSS/JS.

Для GitHub Pages: залейте содержимое папки в репозиторий `pythonistaVP/Download-anime-videos`
(ветка `main`, корень) и включите Pages в настройках — сайт будет на `https://pythonistavp.github.io/Download-anime-videos/`.

## Про живое демо

Демо реально обращается к API каталога (yummyani.me) и к плееру Kodik. Так как страница статичная,
запросы идут через цепочку: напрямую → `cors.eu.org` → `allorigins.win` → `codetabs.com`.
Если все прокси недоступны, демо честно скажет об этом, остальная страница продолжит работать.

Расширение (в отличие от демо) не использует прокси: оно работает внутри браузера со своими
разрешениями на yummyanime.tv и ходит напрямую.

## Ограничения расширения

- Работает только на `yummyanime.tv` — разрешения выданы строго на этот домен.
- Озвучки, которые сайт отдаёт через плеер alloha, недоступны (нет открытых прямых ссылок).
- Качество — ровно то, что отдаёт плеер; перекодирования и апскейла нет.
- DRM-источники не поддерживаются.

## Установка расширения

1. Распакуйте `Download-anime-videos-v1.0.0.zip` (или возьмите готовую папку `extension/`).
2. Откройте `chrome://extensions` (Edge — `edge://extensions`, Opera — `opera://extensions`).
3. Включите «Режим разработчика».
4. «Загрузить распакованное расширение» → выберите папку с `manifest.json`.
5. Откройте любое аниме на yummyanime.tv — появится кнопка «Скачать сезон».
