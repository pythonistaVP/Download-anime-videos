# Download anime videos

**Расширение для браузера, которое скачивает серии и целые сезоны аниме с [yummyanime.tv](https://yummyanime.tv/).**

- **Автор:** [pythonistaVP](https://github.com/pythonistaVP/)
- **Репозиторий:** https://github.com/pythonistaVP/Download-anime-videos
- **Версия:** 1.0.0
- **Работает:** Chrome, Edge, Opera, Brave, Vivaldi, Яндекс.Браузер (Manifest V3, Chromium 116+)
- **Только для сайта:** `yummyanime.tv`

> ⚠️ **Предупреждение.**
> Расширение создано **только для скачивания аниме себе в дорогу** — для личного офлайн-просмотра.
> Пожалуйста, не выкладывайте скачанные файлы в открытый доступ, не распространяйте их и не
> используйте в коммерческих целях. Уважайте правообладателей и правила сайта.

---

## Что умеет

- **Весь сезон в один клик.** Открываете страницу аниме на yummyanime.tv → кнопка «Скачать сезон» → в менеджере уже выбраны все серии, нужное качество и папка. Осталось нажать «Скачать».
- **Выбор студии и озвучки.** Показывает все озвучки, которые есть у тайтла (AniLibria, AniStar, AniDUB, Dream Cast, субтитры и т.д.), с числом серий и диапазоном. Отдельно помечены озвучки, которые технически недоступны для скачивания.
- **Выбор качества.** Реальные качества определяются из самого плеера (360p / 480p / 720p, при наличии — выше), с приблизительным размером на выбранные серии. Если выбранного качества у серии нет — автоматически берётся ближайшее снизу.
- **Отдельные файлы или один ZIP.** Режим «отдельными файлами» пишет MP4 сразу в выбранную папку; режим «одним ZIP» собирает весь сезон в один архив (с ZIP64, поэтому архив любого размера).
- **Выбор серий.** Сетка серий с кликами, готовые пресеты (все / первые 6 / последние 6 / инвертировать), плюс ручной ввод диапазонов вроде `1-12,15`.
- **Имена файлов и папок по шаблону** (`{title} - {ep}.mp4`, папка `{title} [{dub}]`).
- **Менеджер загрузок:** прогресс по каждой серии и общий, скорость, ETA, пауза/продолжить, отмена, «повторить серию», журнал событий, пропуск уже скачанных.
- **Ссылка на репозиторий и разработчика** прямо в интерфейсе (панель на сайте, попап, менеджер, подвал).

## Установка

1. Скачайте архив расширения (`Download-anime-videos.zip`) и распакуйте его в отдельную папку.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Opera — `opera://extensions`).
3. Включите **Режим разработчика** (тумблер справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
5. Откройте или обновите страницу аниме на yummyanime.tv — в правом нижнем углу появится кнопка **«Скачать сезон»**.

## Как пользоваться

1. Откройте страницу сериала на yummyanime.tv (например, `/4934-reinkarnacija-bezrabotnogo...html`).
2. Нажмите плавающую кнопку **«Скачать сезон»** (или правой кнопкой по странице → «Скачать сезон», или иконку расширения в панели браузера).
3. В панели/менеджере выберите:
   - **Озвучку** (студию/перевод);
   - **Качество**;
   - **Серии** (по умолчанию — все);
   - **Как сохранить** — отдельными файлами или одним ZIP;
   - **Папку** кнопкой «Выбрать папку» (в Chromium файлы пишутся напрямую на диск, без ограничения по объёму).
4. Нажмите **«Скачать»** и не закрывайте вкладку менеджера до конца загрузки.

Совет: папка запоминается, поэтому при следующем запуске достаточно нажать «Скачать» — или сразу открыть менеджер с автозапуском (кнопка «Скачать» в панели на сайте).

## Ограничения

- Работает **только** на `yummyanime.tv` (домены вне списка игнорируются).
- Скачиваются озвучки, доступные через **плеер Kodik** — а их большинство. Озвучки, которые есть только у плеера Alloha, помечены как недоступные (у него нет публичного способа получить ссылки на поток).
- Поток берётся как есть: 360/480/720 (иногда 1080/1440, если плеер их отдаёт) — это максимум, который есть на сайте.
- Защищённые DRM/AES-128 потоки не поддерживаются (расширение честно сообщит об этом).
- Ссылки на поток живые примерно 8 часов, поэтому расширение получает их заново перед каждой серией.
- Вкладка менеджера должна оставаться открытой: браузер останавливает страницу при закрытии вкладки.
- Файлы сохраняются в MP4 (поток HLS из MPEG-TS пересобирается на лету).
- В браузерах без File System Access API (Firefox, Safari) серии уходят в «Загрузки» браузера, а большие ZIP-архивы собираются в памяти — для больших сезонов лучше Chromium.

## Как это устроено

```
yummyanime.tv (страница аниме)
        │  content.js — плавающая кнопка и панель выбора
        ▼
background.js  — service worker: разбор ссылки, поиск тайтла, меню, открытие менеджера
        ▼
manager.html/js — вкладка-менеджер: выбор студии/озвучки/качества/серий/папки и движок загрузки
        │
        ├─ lib/yani.js   — API yummyani.me (поиск, метаданные, список серий и озвучек)
        ├─ lib/kodik.js  — плеер Kodik: подпись запроса и получение ссылок на HLS-поток
        ├─ lib/hls.js    — загрузка HLS: параллельные сегменты, порядок, повторы, прогресс
        ├─ lib/vendor mux.js — MPEG-TS → MP4 (fragmented MP4) на лету
        ├─ lib/zip.js    — потоковый ZIP-писатель (STORE, UTF-8, ZIP64)
        └─ lib/sinks.js  — приёмники данных: папка (File System Access), OPFS, память
```

Ключевые детали:

- **Идентификаторы тайтлов не совпадают** у страницы и у API, поэтому менеджер читает название со страницы и ищет тайтл в API с ранжированием по совпадению (название + год + сезон), показывая альтернативы, если совпадение неоднозначное.
- **Kodik не отдаёт готовые ссылки**: нужно запросить страницу плеера, собрать подписанные параметры (`d_sign`, `pd_sign`, `hash`, `id`, …) и вызвать `/ftor`, а полученные ссылки ещё и раскодировать (ROT + base64).
- **Ничего не шифруется и не проксируется**: расширение обращается только к самому сайту, его API и CDN плеера. Никакой аналитики и сторонних серверов.
- Расширение **не обходит платные подписки** — оно сохраняет то, что и так отдаётся плееру в браузере.

## Разработка

```
extension/
├── manifest.json         манифест MV3 (только yummyanime.tv)
├── background.js         service worker (ESM)
├── content.js            панель на странице аниме (Shadow DOM)
├── popup.html/css/js     попап в панели браузера
├── manager.html/css/js   вкладка-менеджер загрузок и движок скачивания
├── lib/
│   ├── util.js           утилиты: байты, шаблоны имён, CRC32, ретраи, пауза
│   ├── yani.js           клиент API yummyani.me + разбор страницы yummyanime.tv
│   ├── kodik.js          извлечение HLS-ссылок из плеера Kodik
│   ├── hls.js            загрузчик HLS (сегменты, порядок, прогресс)
│   ├── zip.js            потоковый ZIP-писатель (STORE / UTF-8 / ZIP64)
│   ├── sinks.js          запись в папку, OPFS и память
│   ├── settings.js       настройки в chrome.storage.local
│   └── idb.js            IndexedDB: запоминание папки сохранения
├── vendor/mux.min.js     mux.js 6.3.0 (Apache-2.0) — MPEG-TS → MP4
└── icons/                16/32/48/128
```

- Зависимостей нет: только vanilla JS и модули ES. Единственный вендорный файл — `vendor/mux.min.js` (сборка с https://github.com/videojs/mux.js, Apache-2.0).
- Проверки: сборка всех модулей через esbuild, сквозной тест HLS → MP4 (реальные сегменты плеера, проверка длительности/разрешения/декодирования кадра), тест ZIP-писателя сторонним ридером (`@zip.js/zip.js`) в обычном и ZIP64-режиме, сверка CRC32 с эталонными контрольными значениями.

## Промо-страница и сборка архива

Исходники расширения лежат в `src/extension/`. Страница проекта (Perchance-генератор) — это `main.pjs` + `index.html` в корне репозитория: описание возможностей, предупреждение о личном использовании, инструкция по установке и **живое демо** — оно резолвит аниме по ссылке yummyanime.tv и показывает найденные озвучки и качества, переиспользуя (`import`) `src/extension/lib/yani.js` и `src/extension/lib/kodik.js`, а запросы делает через `superFetch` (обход CORS на странице вне расширения).

- Готовый архив: https://user.uploads.dev/file/eb8a8a4db0a7127529e5fd7c433e8567.zip — `Download-anime-videos-v1.0.0.zip`, 24 файла, `manifest.json` в корне архива (проверено: содержимое совпадает с текущим `src/extension/`).
- Пересборка: заархивировать содержимое `src/extension/` так, чтобы файлы лежали в корне архива, и загрузить через `upload-plugin`; URL затем обновить в `main.pjs` (`extensionZipUrl`) — страница подставит его сама.
- Баннер для `$meta.image`: `src/assets/download-anime-videos-banner.png` (захощен как https://user.uploads.dev/file/15d0e96d36864d6ace1556b6a635e7e7.png). Единственный ассет вне `src/extension/`; сам в архив расширения не входит.
- Предупреждение «создано только для скачивания аниме себе в дорогу / личный офлайн-просмотр» продублировано в четырёх местах: попап, панель на сайте, менеджер загрузок и страница проекта.
- Статичная версия страницы (для GitHub Pages, Netlify, любого хостинга) собирается из тех же исходников: `index.html` заворачивается в полноценный HTML-документ (мета-теги, favicon из `icons/`), подстановки `[extensionName]`, `[extensionVersion]`, `[extensionZipUrl]`, `[devUrl]`, `[repoUrl]`, `[siteHost]`, `[demoExampleUrl]`, `[warningTitle]`, `[warningText]` заменяются значениями из `main.pjs`, импорты демо переезжают с `./src/extension/lib/*` на `./lib/*`, а `root.superFetch` — на `fetch` через цепочку публичных CORS-прокси: напрямую → `cors.eu.org` → `allorigins.win` → `codetabs.com`, с таймаутом на каждую попытку (проверено вживую: аниме, озвучки и качества резолвятся).
- В архив статичной версии кладутся: `index.html`, `lib/{util,yani,kodik}.js`, `assets/icons/*`, `assets/banner.png`, готовый `Download-anime-videos-v1.0.0.zip` и уже распакованная папка `extension/` (для «Загрузить распакованное расширение»), плюс README с инструкцией. Открывать демо нужно по http(s): на `file://` браузер блокирует ES-модули.
